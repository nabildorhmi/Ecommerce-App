    2. Create `features/cart/store.ts` — Zustand store with persist middleware:
       - State: items (CartItem[])
       - Actions:
         - addItem(product, localeName): If product exists, increment quantity (cap at stockQuantity). If new, push CartItem with quantity=1. Check stock_quantity > 0 before adding.
         - updateQuantity(productId, quantity): If quantity <= 0 remove item, else update (cap at stockQuantity)
         - removeItem(productId): Filter out
         - clearCart(): Set items to []
       - Computed (using get()):
         - totalItems(): sum of all quantities
         - subtotalCentimes(): sum of price * quantity
       - Persist config: name='cart-store', storage=createJSONStorage(() => localStorage), version=1
       - Follow the exact pattern from features/auth/store.ts

    3. Create `features/cart/components/CartItem.tsx`:
       - Props: CartItem
       - Display: thumbnail image, name, unit price (formatted MAD using formatCurrency), quantity controls (- / number / +), subtotal, remove button (IconButton with DeleteOutline icon)
       - Quantity controls: use useCartStore updateQuantity. Min 1, max stockQuantity.
       - Use formatCurrency from shared/utils/currency.ts for prices

    4. Create `features/cart/components/CartDrawer.tsx`:
       - MUI Drawer, anchor="right", controlled by open/onClose props
       - Header: "Cart" title with item count, close button
       - Body: List of CartItem components. If empty, show empty cart message.
       - Footer: Subtotal display (formatCurrency), "Checkout" Button (navigates to /checkout, closes drawer), disabled if cart is empty
       - Use useCartStore for items and subtotalCentimes
       - Use useTranslation for all strings

    5. Create `features/cart/components/CartBadge.tsx`:
       - MUI Badge wrapping a ShoppingCartOutlined icon
       - Badge content: useCartStore totalItems()
       - onClick: triggers CartDrawer open (pass toggle callback as prop)
       - Badge invisible when count is 0

    3. Create `features/checkout/api/orders.ts`:
       - `usePlaceOrder()`: useMutation that POSTs to /orders with PlaceOrderInput body. On success: clearCart (from useCartStore.getState()), invalidate ['orders'] queries, navigate to /orders/{order_number}/confirmation using data from response. Disable button via isPending to prevent double-click.
       - Note: Use useCartStore.getState().clearCart inside onSuccess (outside React render tree, same pattern as auth store)

    4. Create `features/checkout/pages/CheckoutPage.tsx`:
       - Protected route (router wraps in ProtectedRoute)
       - Sections:
         a. **Order Items**: Read-only list of cart items with quantities and subtotals (from useCartStore). If cart is empty, redirect to /products.
         b. **Delivery City**: Autocomplete/Select populated by useDeliveryZones(). On selection, show delivery fee immediately. Use MUI Autocomplete or Select component.
         c. **Phone Number**: Text field, pre-filled from auth store user.phone if available. Required.
         d. **Order Summary**: Subtotal (from cart), delivery fee (from selected zone), total (subtotal + delivery fee). All formatted in MAD. Note: these are display-only — backend recalculates.
         e. **Note**: Optional textarea for customer notes (max 500 chars)
         f. **Place Order button**: Calls usePlaceOrder mutation. Disabled while isPending. Shows "Placing order..." loading state. Sends only: phone, delivery_zone_id, items [{product_id, quantity}], note.
       - Form validation with React Hook Form + Zod: phone required, delivery_zone_id required, items non-empty
       - Error display: Show API validation errors (duplicate order, stock errors) in MUI Alert

    5. Create `features/checkout/pages/OrderConfirmationPage.tsx`:
       - Route: /orders/:orderNumber/confirmation
       - Display: Success icon/message, order number prominently, order summary (items, subtotal, delivery fee, total), delivery city

       - "View My Orders" button → navigates to /orders
       - "Continue Shopping" button → navigates to /products
       - Store confirmation data in location.state from usePlaceOrder navigation (avoid extra API call)
       - If location.state is null (direct URL visit or page refresh), redirect to /orders rather than rendering a broken page
