    2. `createOrder(array $data, int $userId): Order`
       Inside DB::transaction():
       a. Resolve delivery zone — DeliveryZone::where('id', $data['delivery_zone_id'])->where('is_active', true)->firstOrFail()
       b. Duplicate order check — Order::where('phone', $data['phone'])->where('created_at', '>=', now()->subMinutes(10))->whereHas('items', fn($q) => $q->whereIn('product_id', $productIds))->lockForUpdate()->exists() — throw ValidationException if true
       c. Lock products — Product::whereIn('id', $productIds)->where('is_active', true)->lockForUpdate()->get()->keyBy('id')
       d. Validate each item has sufficient stock; calculate subtotal (server-side from DB prices)
       e. Decrement stock — Product::where('id', $item['product_id'])->decrement('stock_quantity', $item['quantity'])
       f. Generate order number — 'ORD-' . now()->format('Ymd') . '-' . strtoupper(substr(uniqid(), -5))
       g. Create Order with server-calculated subtotal, delivery_fee ($zone->fee), total
       h. Create OrderItem records with price snapshots
       i. Create first OrderStatusLog entry (from_status=null, to_status=pending, actor_type='customer')
       j. Return $order->load(['items.product', 'deliveryZone', 'statusLogs'])

    3. `transitionStatus(Order $order, OrderStatus $newStatus, int $actorId, string $actorType, ?string $note = null): Order`
       a. Check $order->status->canTransitionTo($newStatus) — abort(422) if not
       b. Inside DB::transaction(): lockForUpdate the order row, update status, create OrderStatusLog entry with note
       c. Return $order->fresh(['items.product', 'deliveryZone', 'statusLogs'])

    4. `addNote(Order $order, string $note, int $actorId): Order`
       a. Append note to order (update the note field)
       b. Return updated order
