    3. Add deactivation check in `AuthService::login()`:
       - After `$user = User::where('email', $email)->firstOrFail()` and BEFORE the password check

       - This blocks deactivated users from getting a token (AUTH-06 enforcement)

    4. Create `Admin/UserController.php` following the existing AdminProductController pattern:
       - `index()`: `User::with('roles')->paginate(25)` returned via `UserResource::collection($users)->response()`

Include an empty `order_history` array placeholder in the response (Phase 4 will fill this in): add `'order_history' => []` to the response JSON alongside the UserResource.
       - `deactivate(User $user)`: If `$user->hasRole('admin')`, return 422 with `{'message': 'Cannot deactivate admin.'}`. Otherwise set `is_active = false`, return updated UserResource.

    5. Update `routes/api.php`:

         ```
         Route::get('/users', [UserController::class, 'index']);
         Route::get('/users/{user}', [UserController::class, 'show']);
         Route::patch('/users/{user}/deactivate', [UserController::class, 'deactivate']);
         ```
