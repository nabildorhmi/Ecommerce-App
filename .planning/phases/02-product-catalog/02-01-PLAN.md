  <action>
    Follow the Service pattern established in Phase 1 (AuthService). Controllers have zero business logic — delegate to Services.

    **ProductService.php:**
    - `createProduct(array $data, Request $request): Product` — Creates product, stores translations for each locale in `$data['translations']` (fr, en), uploads images from `$request->file('images')` via `addMedia()->toMediaCollection('images')`. See Pattern 4 in RESEARCH.md.
    - `updateProduct(Product $product, array $data, Request $request): Product` — Updates product fields, syncs translations (updateOrCreate by locale), handles new image uploads and image deletions (accept `delete_images[]` array of media IDs to remove).
    - `deleteProduct(Product $product): void` — Deletes product (media cascade handled by medialibrary).

    **CategoryService.php:**
    - `createCategory(array $data): Category` — Creates category with slug, stores translations.
    - `updateCategory(Category $category, array $data): Category` — Updates slug/is_active, syncs translations.
    - `deleteCategory(Category $category): void` — Deletes category (fails if products exist — add check).

    **Customer/ProductController.php:**
    - `index(Request $request)` — Uses `QueryBuilder::for(Product::query())` with all allowed filters per Pattern 2 in RESEARCH.md: `category_id` (exact), `min_price` (callback >=), `max_price` (callback <=), `in_stock` (callback stock_quantity > 0), `search` (callback with locale-scoped FULLTEXT + LIKE fallback for < 4 chars per research code example). Eager load `translations` (filtered to current locale), `media`, `category.translations` (filtered to locale). Default sort `-created_at`. Paginate 12 per page. Only active products (`where('is_active', true)`). Return `ProductResource::collection(...)`.
    - `show(string $slug)` — Find active product by slug in current locale translation. Eager load translations, media, category.translations. Return `new ProductResource(...)`. 404 if not found.

    **Customer/CategoryController.php:**
    - `index()` — Return all active categories with their current-locale translations. Use `CategoryResource::collection(...)`.

    **Admin/ProductController.php:**
    - `index(Request $request)` — List ALL products (including inactive) paginated, with translations/media/category. Uses QueryBuilder with same filters plus `is_active` exact filter.
    - `store(StoreProductRequest $request)` — Validate, delegate to `ProductService::createProduct()`, return `new ProductResource(...)` with 201.
    - `show(Product $product)` — Return product with all translations (all locales, not filtered), media, category.
    - `update(UpdateProductRequest $request, Product $product)` — Validate, delegate to `ProductService::updateProduct()`, return updated resource.
    - `destroy(Product $product)` — Delegate to `ProductService::deleteProduct()`, return 204.

    **Admin/CategoryController.php:**
    - Full CRUD: `index`, `store`, `show`, `update`, `destroy`. Similar pattern. Categories returned with all locale translations for admin.

    **StoreProductRequest.php:** Validate: `sku` required|string|unique:products, `price` required|integer|min:0, `stock_quantity` required|integer|min:0, `category_id` required|exists:categories,id, `is_active` boolean, `translations` required|array, `translations.fr.name` required|string|max:255, `translations.fr.slug` required|string|max:255, `translations.fr.description` nullable|string, `translations.en.name` required|string|max:255, `translations.en.slug` required|string|max:255, `translations.en.description` nullable|string, `attributes` nullable|json (decode from JSON string), `images` nullable|array, `images.*` image|mimes:jpeg,png,webp|max:5120.

    **UpdateProductRequest.php:** Same as Store but `sku` unique rule ignores current product ID. All fields optional (PATCH semantics). `translations` optional. If `translations.fr` present, validate name/slug required within it.

    **StoreCategoryRequest.php:** Validate: `slug` required|string|unique:categories, `is_active` boolean, `translations` required|array, `translations.fr.name` required|string|max:255, `translations.en.name` required|string|max:255.

    **ProductResource.php:** As per Pattern 3 in RESEARCH.md. Returns id, sku, price, stock_quantity, in_stock (boolean), attributes, is_active, name (from first loaded translation), description, slug, category (whenLoaded — CategoryResource), images (whenLoaded — map getMedia('images') to array with id/thumbnail/card/full/original URLs), created_at.

    **ProductCollection.php:** Extends ResourceCollection using ProductResource. Wraps paginator.

    **CategoryResource.php:** Returns id, slug, is_active, name (from first loaded translation), created_at.

    **MediaResource.php:** Returns id, name, thumbnail/card/full/original URLs, size (human_readable_size), mime_type. Per RESEARCH.md MediaResource pattern.

    **routes/api.php:** Add to existing routes:
    - Public (no auth): `GET /products` -> Customer\ProductController@index, `GET /products/{slug}` -> Customer\ProductController@show, `GET /categories` -> Customer\CategoryController@index
    - Inside existing `auth:sanctum` + `role:admin` + `prefix('admin')` group: full resource routes for `products` and `categories` (Admin controllers). Route for `DELETE /admin/products/{product}/media/{media}` for individual image deletion.

    IMPORTANT: For multipart form data, do NOT set `Content-Type` header explicitly in the Axios client — let the browser set it with the boundary. The existing Axios client may have a global `Content-Type: application/json` that needs to be omitted for FormData requests (handled on frontend side in 02-03, but the API must accept multipart/form-data for the store/update endpoints).
  </action>
