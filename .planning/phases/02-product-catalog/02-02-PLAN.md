  <action>
    **types.ts:** Define TypeScript interfaces for the API response shapes:
    - `ProductImage`: { id, thumbnail, card, full, original }
    - `Category`: { id, slug, name, is_active, created_at }
    - `Product`: { id, sku, price, stock_quantity, in_stock, attributes, is_active, name, description, slug, category, images, created_at }
    - `PaginatedResponse<T>`: { data: T[], links: { first, last, prev, next }, meta: { current_page, last_page, per_page, total } }

    **api/products.ts:** Two TanStack Query hooks per Pattern in RESEARCH.md:
    - `useProducts(filters: CatalogFilters)` — `useQuery` with queryKey `['products', filters]`, calls `apiClient.get('/products', { params: filters })`, staleTime 5 min. The `CatalogFilters` type has keys like `filter[category_id]`, `filter[min_price]`, etc., plus `sort` and `page`.
    - `useProduct(slug: string)` — `useQuery` with queryKey `['products', slug]`, calls `apiClient.get('/products/' + slug)`, `enabled: Boolean(slug)`.

    **api/categories.ts:**
    - `useCategories()` — `useQuery` with queryKey `['categories']`, calls `apiClient.get('/categories')`, staleTime 10 min (categories rarely change).

    **hooks/useCatalogFilters.ts:** Per Pattern 9 in RESEARCH.md. Uses `useSearchParams` from `react-router`. Exposes `filters` object (category_id, min_price, max_price, in_stock, search, sort, page) and `setFilter(key, value)` that updates URL params and resets page to 1 on filter change.

    **StockBadge.tsx:** Small MUI Chip component. Props: `inStock: boolean`. Green chip "En stock" / "In stock" when true, red chip "Rupture de stock" / "Out of stock" when false. Use `useTranslation()` for i18n.

    **ProductCard.tsx:** MUI Card component. Props: `product: Product`. Shows: first image (card conversion) or placeholder, product name, formatted price using `formatCurrency(product.price)`, StockBadge, category name. Entire card is a `Link` to `/products/${product.slug}`. Responsive: fixed height card image, truncated name.

    **ProductGrid.tsx:** Props: `products: Product[]`, `loading: boolean`. Responsive MUI Grid: 1 col on xs, 2 on sm, 3 on md, 4 on lg. Maps products to ProductCard. Shows skeleton cards when loading. Shows "no products found" message when empty and not loading.

    **FilterBar.tsx:** MUI Paper with row layout. Components:
    - Search field: MUI TextField with search icon, debounced (300ms) input that sets `filter[search]` via `setFilter`.
    - Category select: MUI Select populated from `useCategories()`, sets `filter[category_id]`.
    - Price range: Two small TextFields for min/max price (in MAD, convert to centimes for API: multiply by 100).
    - In-stock toggle: MUI Switch or Checkbox, sets `filter[in_stock]` to "1" or removes it.
    - Clear filters button: Resets all filters.
    Use `useCatalogFilters()` for all state. Use `useTranslation()` for labels.

    **CatalogPage.tsx:** Composes FilterBar + ProductGrid + MUI Pagination. Gets `filters` from `useCatalogFilters()`, passes them to `useProducts(filters)`. Renders FilterBar at top, ProductGrid with products data, Pagination at bottom (controlled by `filters.page` and `setFilter('page', ...)`). MUI Container for max-width. Page title "Catalogue" / "Catalog" via i18n.

    **router.tsx:** Add routes:
    - `{ path: '/products', element: <CatalogPage /> }`
    - `{ path: '/products/:slug', element: <ProductDetailPage /> }` (import ProductDetailPage — will be created in Task 2, can use lazy import or placeholder)
    - Update `{ path: '/', element: ... }` to redirect to `/products` (or render CatalogPage directly as home page — replace the RtlSmokeTest since Phase 1 testing is done).

    **Locale files:** Add catalog-related strings to both FR and EN translation.json files:
    - FR: catalog.title, catalog.search, catalog.category, catalog.priceRange, catalog.minPrice, catalog.maxPrice, catalog.inStock, catalog.outOfStock, catalog.clearFilters, catalog.noProducts, catalog.showing
    - EN: Same keys with English values.
    Do NOT remove existing translation keys. Merge new keys into existing JSON.

    **CategoryBreadcrumb.tsx:** Props: `category: { slug: string; name: string } | null`. MUI Breadcrumbs component. Items: "Accueil" / "Home" (link to `/products`), category name (link to `/products?filter[category_id]={category.id}`). If no category, show just Home. Use `Link` from `react-router` for navigation.

    - Below: SpecsTable (full width)
