Output: Hardened API configuration files and strict development mode.

<task type="auto">
  <name>Task 1: Rate-limit auth routes and tighten CORS</name>
  <files>trotinette-api/routes/api.php, trotinette-api/config/cors.php</files>
  <action>
In routes/api.php:
- Add throttle middleware to the four public auth routes:
  - POST /auth/login: `->middleware('throttle:5,1')` (5 attempts per minute)
  - POST /auth/register: `->middleware('throttle:3,1')` (3 attempts per minute)
  - POST /auth/forgot-password: `->middleware('throttle:3,1')` (3 attempts per minute)
  - POST /auth/reset-password: `->middleware('throttle:5,1')` (5 attempts per minute)
- Do NOT change the existing route definitions or middleware on protected/admin routes. Only ADD the throttle middleware to the 4 auth routes listed above.

In config/cors.php:
- Change `'allowed_headers' => ['*']` to `'allowed_headers' => ['Content-Type', 'Authorization', 'X-Requested-With', 'Accept', 'Accept-Language']`
- Change `'max_age' => 0` to `'max_age' => 86400` (cache preflight for 24 hours to reduce OPTIONS requests)
- Keep `'allowed_origins' => ['http://localhost:5173']` unchanged (correct for development)
- Keep `'allowed_methods' => ['*']` unchanged (needed for PUT/PATCH/DELETE)
  </action>
  <verify>
Run `php artisan route:list` from trotinette-api/ directory and confirm the 4 auth routes show throttle middleware.
Read config/cors.php and confirm allowed_headers lists specific headers (not '*').
  </verify>
  <done>Auth routes have throttle middleware applied. CORS allows only specific headers. Frontend still works with the restricted CORS headers.</done>
</task>

  <action>
In config/sanctum.php:
- Change `'expiration' => null` to `'expiration' => env('SANCTUM_TOKEN_EXPIRATION', 43200)` (30 days in minutes = 43200). Using env() allows production override without code changes.

In app/Providers/AppServiceProvider.php:
- Add `use Illuminate\Database\Eloquent\Model;` at the top
- Inside the boot() method, BEFORE the existing ResetPassword::createUrlUsing() call, add:
  ```php
  // Strict mode: catch N+1 queries and missing attributes in development
  Model::preventLazyLoading(! $this->app->isProduction());
  Model::preventAccessingMissingAttributes(! $this->app->isProduction());
  ```
- Keep the existing ResetPassword::createUrlUsing() code unchanged.
  </action>
