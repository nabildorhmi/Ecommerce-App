  <action>
With `Model::preventLazyLoading()` now active in development, any lazy-loaded relationship will throw a `LazyLoadingViolationException`. Audit every controller method that accesses model relations and ensure explicit eager loading via `with()` or `load()`.

Read each controller file carefully. For every query that returns models, check if the corresponding Resource or response accesses any relationship. If so, ensure the relationship is eager-loaded.

**Common patterns to check:**
1. `Model::find($id)` or `Model::findOrFail($id)` — needs `->load('relations')` or use `Model::with('relations')->findOrFail($id)`
2. `$model->relationName` accessed in Resource — relationship must be eager-loaded in controller
3. Spatie QueryBuilder `allowedIncludes()` — may not auto-eager-load; verify
4. `$order->items->each(...)` — items must be eager-loaded

**Specific areas to audit (read each file first, then fix):**

Admin OrderController:
- `index()`: Ensure orders load with `user`, `items.product`, `items.variant`
- `show()`: Ensure order loads with `items.product`, `items.variant.attributeValues`, `statusLogs`, `user`
- `transition()`: After status transition, ensure fresh() includes all needed relations
- `invoice()`: Ensure order loads relations needed for invoice generation

Admin ProductController:
- `index()`: Ensure products load with `category`, `media`, `variants`
- `show()`: Ensure product loads with `category`, `media`, `variants.attributeValues.attribute`

Admin UserController:
- `index()`: If user list accesses roles, ensure roles are eager-loaded
- `show()`: If user detail accesses orders or roles, ensure eager-loaded

Customer OrderController:
- `index()`: Ensure customer orders load with `items.product`, `items.variant`
- `show()`: Ensure order loads all needed relations

Customer ProductController:
- `index()`: Ensure products load with `category`, `media`, `variants`
- `show()`: Ensure product loads with `category`, `media`, `variants.attributeValues.attribute`

Also check these controllers (read first, only modify if needed):
- Admin CategoryController, Admin DeliveryZoneController, Admin DashboardController
- Admin HeroBannerController, Admin PageController, Admin AttributeController, Admin VariantController

**Do NOT change business logic.** Only add/ensure `with()` or `load()` calls for relations that are accessed downstream.

If a controller already has proper eager loading, leave it unchanged and note it in the summary.
