  <action>
    1. **Create migration** `create_wishlists_table`:
       - `id()`, `foreignId('user_id')->constrained()->cascadeOnDelete()`, `foreignId('product_id')->constrained()->cascadeOnDelete()`, `timestamps()`
       - Add `$table->unique(['user_id', 'product_id'])` to prevent duplicate pivot rows
       - Run: `php artisan make:migration create_wishlists_table` then fill the up/down methods

    2. **Add model relations:**
       - In `User.php`: add `wishlist(): BelongsToMany` returning `$this->belongsToMany(Product::class, 'wishlists')->withTimestamps()`
       - In `Product.php`: add `wishlistedBy(): BelongsToMany` returning `$this->belongsToMany(User::class, 'wishlists')->withTimestamps()`

    3. **Create `Customer\WishlistController`:**
       - `index(Request $request)`: Return `ProductResource::collection($request->user()->wishlist()->with(['translations', 'media'])->paginate(20))`
       - `toggle(Request $request, Product $product)`: Call `$request->user()->wishlist()->toggle($product->id)`, return `{ is_wishlisted: bool, product_id: int }`
       - Pattern matches existing `Customer\OrderController` — thin controller, no service class needed

    4. **Update `ProductResource`:**
       - Add `is_wishlisted` field: `'is_wishlisted' => auth()->check() ? $this->wishlistedBy->contains('id', auth()->id()) : false`
       - This field only returns meaningful data when `wishlistedBy` is eager-loaded (single product endpoint). For catalog list, it will return false (no eager load, no N+1)
       - In the customer `ProductController::show()` method, add `wishlistedBy` to the eager-load list so the product detail page gets the `is_wishlisted` flag

    5. **Register routes** in `api.php` inside the existing `auth:sanctum` group (NOT inside admin group):
       - `Route::get('/wishlist', [WishlistController::class, 'index']);`
       - `Route::post('/wishlist/{product}', [WishlistController::class, 'toggle']);`
       - Add the `use` import for `App\Http\Controllers\Customer\WishlistController`

    6. **Run migration:** `php artisan migrate`
  </action>
  <verify>
    - `php artisan migrate:status` shows wishlists table as migrated
    - `php artisan route:list --path=wishlist` shows both GET /api/wishlist and POST /api/wishlist/{product}
    - Manual curl: authenticated POST to `/api/wishlist/{product_id}` returns `{ is_wishlisted: true, product_id: N }`; second POST returns `{ is_wishlisted: false }`
  </verify>
